# Rivers End

Build a production-ready responsive boutique hotel website based on the attached reference screenshots. O nome é Rivers End - Guesthouse. E fica em Portland Jamaica 



IMPORTANT:

The screenshots are references for the visual language, layout, typography, spacing, image composition, mobile behavior and overall feeling.



DO NOT copy the original hotel's branding, logo, name, colors or identity.



Create an original boutique hotel website that follows the same level of elegance, editorial composition, restraint and sophistication.



The website should feel like a high-end independent countryside boutique hotel: intimate, refined, calm, natural, warm and design-led.



The main purpose of the website is to showcase THREE suites and drive visitors to an external booking platform.



ONLY CREATE THESE PAGES:



1. Homepage

2. About

3. Suite 01

4. Suite 02

5. Suite 03



There should be NO separate Experiences page, Contact page, Events page, Gift Shop, Blog or other pages.



The ONLY conversion CTA throughout the website is "Book now" and it must link to an external booking URL.

RESPONSIVE DESIGN

tablet 768–1024px

desktop > 1024px

- generous vertical spacing

- portrait photography

- two-column image grids where appropriate

- large editorial typography

- fixed bottom booking bar

Desktop:



- maximum content width approximately 1400px

- generous margins

- asymmetrical layouts

- alternating image/text compositions

- large whitespace

- refined editorial grids



The mobile version is extremely important.



Match the proportions and rhythm of the provided mobile references closely.
